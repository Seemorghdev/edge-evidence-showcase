# Contributing

This repository is a generated public product. Authoritative corrections are made
upstream in the private canonical source and then regenerated; direct changes to
generated files are not accepted as a new source of truth.

Security-sensitive reports must use **GitHub Private Vulnerability Reporting / GitHub
Security Advisories**, not an ordinary public issue. Do not include credentials,
provider coordinates, retained evidence, or personal data in public issues. See
`SECURITY.md`.

General documentation and reproducibility problems may use ordinary GitHub issues
after all private material has been removed. No personal email address is published;
a dedicated monitored mailbox requires a later reviewed change.
