# Security policy

Use **GitHub Private Vulnerability Reporting / GitHub Security Advisories** for
security-sensitive reports. Do not place credentials, provider coordinates, retained
evidence, personal data, or other private operational material in public issues.

No personal email address is published for security reporting. A dedicated monitored
security mailbox requires a later reviewed change before it may be added.

This synthetic repository is not a production service and has no deployment, IAM,
scheduler, or live-provider runbook. General non-security documentation and
reproducibility problems may use ordinary GitHub issues only after private material
has been removed.
