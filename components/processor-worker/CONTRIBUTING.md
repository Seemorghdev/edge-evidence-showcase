# Contributing

This repository is a generated product from private canonical source (identity withheld). Authoritative
changes are upstream-first and arrive through deterministic regeneration; direct
changes to projected files are not a new source of truth and may be replaced.

Use ordinary GitHub issues only for non-security documentation, reproducibility, and
public product questions that contain no credentials, provider coordinates, retained
evidence, personal data, or private operational details.

Security-sensitive reports must use **GitHub Private Vulnerability Reporting / GitHub
Security Advisories**, not an ordinary public issue. See `SECURITY.md`. No personal
email address is published; adding a dedicated monitored mailbox requires a later
reviewed change.

Public provenance intentionally records only the redacted source label, exact
candidate path count, public-safe content digest, dependency-boundary identity,
license, policy, and verification commands. The exact private source binding remains
private validation evidence.
